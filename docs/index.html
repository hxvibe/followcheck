설치

앱 다운로드 (APK) 약 30KB · 서버 없이 폰에서 인스타그램과 직접 통신해요
  1. 다운로드 "유해할 수 있는 파일" 경고가 뜨면 그래도 다운로드.
  2. 설치 다운로드한 파일을 열고, "출처를 알 수 없는 앱" 허용을 켠 뒤 설치. Play 프로텍트 경고가 뜨면 세부정보 → 무시하고 설치.
  3. 앱 열고 인스타그램 로그인 앱 안에 인스타그램 공식 로그인 화면이 나와요. 로그인하면 맞팔 확인 화면이 자동으로 열려요. 2단계 인증도 그대로 돼요.
비밀번호는 인스타그램 공식 로그인 화면에만 입력돼요. 이 앱은 따로 저장하거나 어디에도 보내지 않아요.

Safari 북마크로 실행

아이폰은 앱스토어 밖 앱 설치가 막혀 있어서, Safari 북마크 하나로 같은 화면을 띄워요. 처음 한 번만 설정하면 돼요.

  1. 이 페이지를 북마크에 추가 하단 공유 → 북마크 추가 → 이름을 followcheck 로 저장.
  2. 북마크 주소를 코드로 바꾸기 북마크(책 아이콘) → 편집 → followcheck → 주소 칸을 모두 지우고 복사한 코드 붙여넣기 → 완료.
  3. Safari로 instagram.com 열고 로그인 링크가 인스타 앱으로 열리면 주소창에 직접 instagram.com 입력.
  4. 북마크 실행 주소창을 누르고 followcheck 입력 → 아래 뜨는 북마크 항목을 탭 (엔터 X). 맞팔 확인 화면이 열려요.

북마크바에 끌어다 놓기

북마크바가 안 보이면 Ctrl/⌘+Shift+B. instagram.com 에 로그인한 상태에서 클릭하면 열려요.

주의

인스타그램 공식 기능이 아닌 비공식 도구예요.
  • 하루에 몇 번 정도만 확인하세요. 너무 자주 하면 인스타가 잠시 요청을 막을 수 있어요.
  • 팔로워가 많으면 계정 보호를 위해 일부러 천천히(수 분) 불러와요.
  • 결과는 이 기기에만 저장돼요. 어떤 서버로도 보내지 않아요.

안 될 때

APK 설치가 막혀요

설정 → 앱 → 특별한 접근(또는 보안) → "출처를 알 수 없는 앱 설치"에서 다운로드에 쓴 앱(Chrome, 내 파일 등)을 허용하세요. 삼성은 "자동 차단기"가 켜져 있으면 잠시 꺼야 해요.

앱 업데이트는 어떻게 해요?

같은 다운로드 버튼으로 새 APK를 받아 설치하면 덮어써져요. 로그인과 지난 결과는 그대로 남아요.

“로그인이 필요해요”가 떠요

아이폰/PC는 앱이 아니라 브라우저(Safari/Chrome)에서 instagram.com 에 로그인되어 있어야 해요. 로그인 후 새로고침하고 다시 실행하세요.

“요청이 너무 많다”가 떠요

인스타가 잠시 막은 상태예요. 30분~몇 시간 쉬었다가 다시 시도하세요. 몇 번은 자동으로 기다렸다 이어서 진행해요.

갑자기 안 돼요

인스타그램 내부 방식이 바뀌면 멈출 수 있어요. 새 버전이 올라오면 앱은 다시 설치, 북마크는 코드를 다시 붙여넣으면 돼요.
