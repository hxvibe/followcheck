1. 설치 (한 번만)

  1. 코드 복사
  2. 이 페이지를 북마크에 추가
    하단 공유 버튼 → 북마크 추가 → 이름을 followcheck 로 저장.
  3. 북마크 주소를 코드로 바꾸기
    북마크(책 아이콘) → 편집 → followcheck 선택 → 주소 칸을 모두 지우고 복사한 코드를 붙여넣기 → 완료.
  1. 코드 복사
  2. 이 페이지를 북마크에 추가
    오른쪽 위 ⋮ → ☆ 누르기 → 하단에 뜨는 수정.
  3. 이름·주소 바꾸기
    이름은 followcheck, URL 칸은 모두 지우고 복사한 코드를 붙여넣은 뒤 저장.
  1. 북마크바에 끌어다 놓기
    북마크바가 안 보이면 Ctrl/⌘+Shift+B
    ⇄ followcheck
    드래그가 안 되면: 아무 페이지나 북마크한 뒤 주소(URL)를 아래 코드로 바꿔주세요.
  2. (대안) 개발자 도구 콘솔에 붙여넣기
    instagram.com 에서 F12 → Console 탭 → 아래 코드를 붙여넣고 Enter. 크롬이 막으면 allow pasting 을 먼저 입력하세요.
코드 직접 보기 / 수동 복사

2. 사용

  1. 브라우저로 instagram.com 열고 로그인
    인스타 앱이 아니라 Safari/Chrome 에서 웹으로 열어야 해요. 링크가 앱으로 열리면 주소창에 직접 입력하세요.
  2. 북마클릿 실행
    모바일: 주소창을 누르고 followcheck 입력 → 아래 뜨는 북마크 항목(☆/책 아이콘)을 탭. 엔터를 누르면 검색이 되니 주의!
    PC: 북마크바의 followcheck 클릭.
  3. 결과 확인
    팔로워·팔로잉을 천천히 불러온 뒤 탭별로 보여줘요. 다음에 다시 실행하면 변화 탭에서 그 사이 나를 언팔한 사람을 볼 수 있어요.

주의

인스타그램 공식 기능이 아니라, 인스타 웹이 내부적으로 쓰는 API를 내 로그인 세션으로 호출하는 비공식 도구예요.
  • 하루에 몇 번 정도만 실행하세요. 너무 자주 돌리면 인스타가 일시적으로 요청을 제한할 수 있어요.
  • 팔로워가 수천 명 이상이면 계정 보호를 위해 일부러 천천히(수 분) 불러와요.
  • 데이터는 어떤 서버로도 전송되지 않아요. 결과 스냅샷만 브라우저(instagram.com 저장소)에 남아요.

안 될 때

“로그인이 필요해요”가 떠요

앱이 아니라 브라우저에서 instagram.com 에 로그인되어 있어야 해요. 로그인 후 페이지를 새로고침하고 다시 실행하세요.

북마크를 눌러도 아무 일도 안 일어나요

주소 칸에 코드가 javascript: 로 시작하는지 확인하세요. 일부 브라우저는 붙여넣을 때 앞부분을 지워요. 아이폰은 북마크 메뉴에서 직접 탭하는 방식도 돼요.

“요청이 너무 많다(429)”가 떠요

인스타가 잠시 막은 상태예요. 30분~몇 시간 쉬었다가 다시 시도하세요. 자동으로 몇 번은 기다렸다 재시도해요.

인스타가 업데이트돼서 안 되는 것 같아요

내부 API가 바뀌면 동작이 멈출 수 있어요. 두 가지 방식(REST, GraphQL)을 차례로 시도하도록 되어 있고, 둘 다 막히면 코드 수정이 필요해요.
